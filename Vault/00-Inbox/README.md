# 00-Inbox

Unsorted capture. Daily notes land here as `YYYY-MM-DD.md`. Triage
periodically: promote anything worth keeping into `10-Projects/<slug>/` or
`20-Knowledge/` with proper frontmatter, and delete or archive the rest.
Nothing here should be treated as durable — the FTS index still finds it,
but don't rely on inbox notes staying put long-term.
