# 90-Archive

Superseded or dead notes, kept for history rather than active recall. Move a
note here (and set its `status: archived`) instead of deleting it outright —
the FTS index still finds it if you ever need to dig it up, just don't
expect it to surface in day-to-day queries with the same priority as active
notes.
